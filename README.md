# NEBULA ∞
موقع تفاعلي كبير يعمل كـ Static Site، بدون Node.js أو قاعدة بيانات أو سيرفر.

## التشغيل
افتح `index.html` مباشرة، أو ارفع الملفات الثلاثة إلى GitHub Pages.

## ما يحتويه
- مختبر لبناء هوية عالمك وحفظها في localStorage.
- نظام ذكريات قابل للإضافة.
- أربع ألعاب مختلفة تماماً عن الأسئلة: صائد البرق، متاهة الضوء، مدار مستقر، نبضة الهدف.
- XP وإنجازات وتقدم.
- تصدير واستيراد بيانات العالم JSON.
- مظهر فاتح/داكن.
- متجاوب مع الهاتف.

## GitHub Pages
ارفع `index.html` و`styles.css` و`app.js` إلى مستودع، ثم فعّل Pages من إعدادات المستودع واختر الفرع والمجلد الذي يحتوي الملفات.
